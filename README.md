## IDEs & Editors

- [Glim](https://github.com/NeoPanic/Glim) — macOS file viewer with Markdown preview and basic text editing
- [VS Code](https://code.visualstudio.com/) — The most popular code editor, thousands of extensions
- [Cursor](https://cursor.sh/) — AI-first code editor built on VS Code
- [Zed](https://zed.dev/) — High-performance editor written in Rust
- [Windsurf](https://codeium.com/windsurf) — AI-powered IDE by Codeium
- [JetBrains Fleet](https://www.jetbrains.com/fleet/) — Lightweight multi-language IDE

## Free Hosting

- [Vercel](https://vercel.com/) — Frontend & serverless, free for hobby projects
- [Netlify](https://netlify.com/) — JAMstack hosting with CI/CD, 100GB bandwidth free
- [Railway](https://railway.app/) — Full-stack hosting, $5 free credit/month
- [Render](https://render.com/) — Free web services, static sites, PostgreSQL
- [Fly.io](https://fly.io/) — Edge hosting, 3 shared VMs free
- [GitHub Pages](https://pages.github.com/) — Free static site hosting from repos
- [Cloudflare Pages](https://pages.cloudflare.com/) — Unlimited bandwidth, 500 builds/month free

## CI/CD

- [GitHub Actions](https://github.com/features/actions) — 2,000 min/month free for public repos
- [GitLab CI](https://docs.gitlab.com/ee/ci/) — 400 min/month free
- [CircleCI](https://circleci.com/) — 6,000 min/month free
- [Dagger](https://dagger.io/) — Programmable CI/CD engine

## APIs (No Key Needed)

- [Open-Meteo](https://open-meteo.com/) — Weather forecasts, no registration
- [JSONPlaceholder](https://jsonplaceholder.typicode.com/) — Fake REST API for testing
- [Hacker News API](https://github.com/HackerNews/API) — Stories, comments, users
- [Reddit JSON](https://www.reddit.com/.json) — Append .json to any Reddit URL
- [Wikipedia API](https://en.wikipedia.org/api/rest_v1/) — Article content, search, media
- [arXiv API](https://arxiv.org/help/api/) — Scientific paper metadata
- **More:** [awesome-no-auth-apis](https://github.com/spinov001-art/awesome-no-auth-apis) — 200+ free APIs

## Databases

- [Supabase](https://supabase.com/) — PostgreSQL + auth + storage, free tier generous
- [PlanetScale](https://planetscale.com/) — Serverless MySQL (hobby plan)
- [Neon](https://neon.tech/) — Serverless PostgreSQL, 0.5GB free
- [Upstash](https://upstash.com/) — Serverless Redis & Kafka, pay-per-request
- [Turso](https://turso.tech/) — Edge SQLite, 9GB storage free
- [MongoDB Atlas](https://www.mongodb.com/atlas) — 512MB free cluster

## Monitoring & Logging

- [Sentry](https://sentry.io/) — Error tracking, 5K events/month free
- [Grafana Cloud](https://grafana.com/products/cloud/) — Free tier: 10K metrics, 50GB logs
- [Better Stack](https://betterstack.com/) — Uptime monitoring, 10 monitors free
- [Highlight.io](https://highlight.io/) — Session replay + error monitoring, open source

## Design & Prototyping

- [Figma](https://figma.com/) — Collaborative design, 3 projects free
- [Excalidraw](https://excalidraw.com/) — Hand-drawn style diagrams, no signup
- [tldraw](https://tldraw.com/) — Infinite canvas whiteboard
- [Penpot](https://penpot.app/) — Open-source design tool

- [Firebase Auth](https://firebase.google.com/products/auth) — 10K verifications/month free
